# Добавление в автозагрузку

- [ ] В General появляется чекбокс "Добавить в автозагрузку", при сохранении настроек производится процесс регистрации приложения в автозапуск. если чекбокс снять - при сохранении из автозагрузки убирается.

- [ ] В случае редактирования конфига аналогично, во время старта проверяется наличие опции и добавляется\удаляется из автозагрузки

Опция существует только для windows, linux вне скопа
