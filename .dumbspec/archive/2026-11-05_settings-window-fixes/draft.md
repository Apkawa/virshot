# draft: Правки для окна настроек

Правки для окна настроек

## Settings

- [ ] кнопка Apply должны быть в самом низу справа, и добавляются несколько:  "Apply", "OK", "Cancel"
- [ ] окно настроек не требует кнопок сворачивания и на весь экран. только закрыть.

### General

- [ ] под Window template разместить аккордеон со справкой по шаблонам, просто список вида, примерно так:
```
%t -- window title
%ext - extension without dot, eg 'png'
```

### Hotkeys

- [ ] название, кнопки привязки выровнять таблицей
- [ ] Ошибка-предупреждение - слева от кнопки привязки.
- [ ] возможность очистить биндинг через Backspace, (показать подсказку в начале формы, Esc для отмены, Backspace для очистки)
- [ ] Нет возможности назначить биндинг на PrintScreen|Ins...PgDown, работает только через правку конфига и перезапуска приложения. cейчас биндятся по итогу A-Z,F1-F12 + опциональные модификаторы
- [ ] для биндов геймпада использовать человекочитаемые имена, например `XboxX` вместо `unknown:9`. `unknown:<number>` только в случае если кнопка совсем не распозналась (какой нибудь очень нестандартный геймпад)
- [ ] В случае биндингов которые дублируются, например везде забиндить Share, показывать предупреждение и не давать такое сохранять

### Overlay

- [ ]  Добавить кнопку теста оверлея, думаю справа от галочки "Show overlay toast", кнопка неактивна если галочка снята

## Доработки v2 (2026-11-06, дословно, приложен annotated screenshot вкладки Hotkeys)

2) прижать блок кнопок к низу
3) при биндинге геймпада нет возможности очистить или отменить через Esc|Backspace
